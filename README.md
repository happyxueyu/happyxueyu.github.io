# 精进群工具箱（测试）

定时视频播放页：打开即待机，到点自动播放指定视频，**播完一遍自动停止**，全程不可手动控制。

- 每天早上 **5:30** 自动播放 视频1，播完即停
- 每天晚上 **20:00** 自动播放 视频2，播完即停
- 所有打开页面的人按同一时间表观看同一视频
- 页面底部备注反馈邮箱

在线地址：<https://happyxueyu.github.io/>

## 使用方法

1. 提前打开页面（手机/电脑/平板均可）
2. 点击「开启声音」按钮——这是浏览器安全策略要求的一次性操作，点击后到点才能**有声**自动播放
3. 保持页面开着即可，到点自动全屏播放，播完自动回到待机界面

## 修改播放时间 / 更换视频

编辑 `js/app.js` 顶部的配置：

```js
const SCHEDULE = [
  { id: "am", name: "早课 · 视频1", time: "05:30", video: "test-media/demo-video.mp4" },
  { id: "pm", name: "晚课 · 视频2", time: "20:00", video: "test-media/demo-video.mp4" },
];
```

- `time`：24 小时制，`"HH:MM"`
- `video`：站内文件路径（内置视频）或 https 直链（`.mp4` 等浏览器可播放格式）

**内置视频限制：** 单文件 ≤ 100MB（GitHub 硬限制，建议 ≤ 50MB）。过大视频需先压缩（降低分辨率/码率）。

更新代码后推送即可生效（GitHub Pages 1~2 分钟自动构建）。

## 技术说明

- 纯静态单页，零依赖；视频内置在站点中，Service Worker 预缓存后**断网也能照常播放**
- 按访客本地时钟触发；到场后 15 分钟内打开页面会补播当天场次（一场一天只播一次）
- PWA：可添加到手机/电脑桌面当 APP 用
- 声明了屏幕常亮（Wake Lock，视浏览器支持），降低到点时设备已休眠的概率
