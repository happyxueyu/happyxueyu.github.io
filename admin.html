如何创建令牌？（点开看步骤）
  1. 登录 GitHub → 右上角头像 → Settings
  2. 左侧最底 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token：名称随意；Repository access 选 Only select repositories → 选 happyxueyu/happyxueyu.github.io
  4. Permissions → Repository permissions → Contents 设为 Read and write，其余保持默认
  5. 生成后复制令牌（只显示一次），粘贴到上面输入框
